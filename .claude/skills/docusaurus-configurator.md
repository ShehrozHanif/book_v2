# Docusaurus Configurator Skill

## Purpose
Configure and customize Docusaurus sites for optimal documentation structure and user experience.

## Key Responsibilities
- Initialize Docusaurus project structure
- Configure docusaurus.config.js settings
- Set up sidebars.js for documentation hierarchy
- Configure navbar with custom links and dropdown menus
- Set up custom styling and theme configuration
- Configure search functionality
- Set up multi-language/localization

## When to Use
- Starting a new Docusaurus project
- Modifying site structure or configuration
- Adding custom branding and styling
- Setting up multi-language support
- Configuring deployment settings

## Typical Outputs
- Configured `docusaurus.config.js`
- Structured `sidebars.js` file
- Custom theme files if needed
- Static asset organization
- Build and deployment configuration

## Configuration Areas

### Site Metadata
- Title, tagline, URL, favicon
- Social media links
- Repository configuration
- Analytics setup

### Navigation Structure
- Navbar items and dropdowns
- Sidebar organization
- Footer structure and links
- Search functionality

### Styling
- Color schemes
- Typography settings
- Custom CSS
- Responsive breakpoints

### Advanced Features
- Plugin configuration (search, PWA, etc.)
- Versioning setup
- API documentation integration
- Custom pages and redirects

## Best Practices
- Organize documentation logically by feature/topic
- Use consistent naming conventions
- Keep sidebar structure flat (max 3 levels)
- Implement breadcrumb navigation
- Set up search metadata properly
- Test configuration locally before deployment
