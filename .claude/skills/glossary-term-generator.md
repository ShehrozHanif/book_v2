# Glossary Term Generator Skill

Create comprehensive technical glossary entries.

## Entry Components
- Technical term
- Definition (clear, concise)
- Examples
- Related terms
- Context of usage
- Pronunciation guide (if applicable)

## Output Format
Each entry should be usable in both English and Urdu contexts.
