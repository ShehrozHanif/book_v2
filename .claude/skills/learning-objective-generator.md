# Learning Objective Generator Skill

Create SMART learning objectives (Specific, Measurable, Achievable, Relevant, Time-bound).

## Bloom's Taxonomy Levels
- Remember: Recall facts
- Understand: Explain concepts
- Apply: Use knowledge
- Analyze: Break down components
- Evaluate: Make judgments
- Create: Produce new work

## Output Format
After completing this chapter, learners will be able to:
1. [Action verb] [content] [context]
2. [Action verb] [content] [context]
3. [Action verb] [content] [context]
