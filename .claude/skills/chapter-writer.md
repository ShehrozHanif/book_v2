# Chapter Writer Skill

## Purpose
Create complete, well-structured technical chapters for educational textbooks.

## Key Responsibilities
- Write comprehensive chapter content
- Create learning objectives (3-5 per chapter)
- Structure content progressively (basics to advanced)
- Include relevant code examples
- Add real-world applications
- Write clear explanations
- Provide practical context

## Chapter Structure
- Opening hook/context
- Learning objectives
- Key concepts introduction
- Main content sections
- Code examples with explanations
- Practical applications
- Summary section
- Key takeaways

## Content Guidelines
- Clear, accessible writing for learners
- Proper technical terminology
- Progressive complexity
- Multiple learning styles (text, code, examples)
- Real-world relevance
- Clear transitions between sections
