# Exercise Generator Skill

Create practical, hands-on exercises that reinforce learning objectives.

## Exercise Types
- Coding challenges
- Configuration tasks
- Debugging problems
- Design questions
- Implementation projects
- Case study analysis

## Exercise Components
- Clear problem statement
- Starting code/data (if applicable)
- Expected output/results
- Solution with explanation
- Difficulty level
- Time estimate
