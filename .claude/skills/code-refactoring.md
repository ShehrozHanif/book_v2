# Code Refactoring Skill

Improve existing code quality through refactoring.

## Refactoring Goals
- Extract methods/functions
- Remove duplication
- Improve naming
- Simplify complexity
- Optimize performance
- Enhance testability

## Refactoring Patterns
- Extract method
- Extract variable
- Extract class
- Replace magic numbers
- Simplify conditionals
