# Content Structuring Skill

## Purpose
Organize technical content into clear, logical hierarchical structures.

## Key Responsibilities
- Create logical section hierarchy
- Organize by learning progression
- Establish consistent formatting
- Create table of contents
- Link related sections
- Ensure proper flow between topics

## Structuring Guidelines
- Use H2-H4 for hierarchy (H1 reserved for chapter title)
- Group related topics together
- Progressive complexity within sections
- Clear section introductions
- Smooth transitions
- Consistent formatting patterns

## Output
- Markdown with proper heading structure
- Table of contents
- Section summaries
- Cross-references
