# FastAPI Endpoint Generator Skill

Create REST API endpoints with proper validation and documentation.

## Endpoint Components
- Route definition
- Request model (Pydantic)
- Response model
- Error handling
- Validation rules
- Documentation
- Authentication (if needed)

## Output Includes
- Complete endpoint code
- Model definitions
- Error responses
- OpenAPI documentation
