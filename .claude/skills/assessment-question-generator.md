# Assessment Question Generator Skill

Create comprehensive assessment questions at various difficulty levels.

## Question Types
- Multiple choice
- Short answer
- Fill-in-the-blank
- True/false
- Scenario-based
- Code analysis

## Question Design
- Clear, unambiguous wording
- Aligned with learning objectives
- Varying difficulty levels
- Answer keys with explanations
- Proper distractor creation
