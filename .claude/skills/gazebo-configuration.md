# Gazebo Configuration Skill

Create robot descriptions for simulation.

## Robot Description Components
- Links and joints
- Inertia properties
- Visual geometry
- Collision geometry
- Sensor definitions
- Plugin configurations

## Formats Supported
- URDF (Unified Robot Description Format)
- SDF (Simulation Description Format)
