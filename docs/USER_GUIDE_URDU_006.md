## Getting Started / شروع کریں

### مرحلہ 1: لاگ ان کریں (Step 1: Login)

اردو زبان استعمال کرنے کے لیے آپ کو پہلے اپنے اکاؤنٹ میں لاگ ان کرنا ہوگا۔

To use Urdu language, you must first log into your account.

**مراحل | Steps**:
1. ویب سائٹ پر جائیں | Go to website
2. "لاگ ان" بٹن پر کلک کریں | Click "Login" button
3. اپنا صارف نام اور پاس ورڈ درج کریں | Enter username and password
4. "داخل ہوں" بٹن پر کلک کریں | Click "Submit" button

**مثال | Example**:
```
صارف نام: your_username
پاس ورڈ: your_password
```

## Select Urdu Language / اردو زبان منتخب کریں

### مرحلہ 2: اردو زبان منتخب کریں (Step 2: Choose Urdu)

جب آپ لاگ ان ہو جائیں، تو آپ اردو زبان منتخب کر سکتے ہیں۔

Once logged in, you can select the Urdu language.

**مراحل | Steps**:

1. **زبان منتخب کریں | Select Language**:
   - چیٹ بوٹ واجہ کے اوپر "English" یا "اردو" بٹن تلاش کریں
   - Look for "English" or "اردو" button at the top of chatbot

2. **اردو بٹن پر کلک کریں | Click Urdu Button**:
   ```
   [English]  [اردو]  ← یہاں کلک کریں | Click here
   ```

3. **تصدیق | Confirmation**:
   - صفحہ تبدیل ہوگا اور دائیں سے بائیں (RTL) ہو جائے گا
   - Page will change and become right-to-left (RTL)
   - ✓ اردو منتخب ہو گیا ہے | ✓ Urdu is now selected

### اردو منتخب ہونے کے بعد کیا ہوتا ہے؟ | What happens after selecting Urdu?

✅ تمام متن اردو میں دکھایا جائے گا | All text will be shown in Urdu
✅ صفحہ دائیں سے بائیں ہوگا | Page will be right-to-left
✅ چیٹ بوٹ اردو میں جواب دے گا | Chatbot will respond in Urdu
✅ آپ کی ترجیح محفوظ ہوگی | Your preference will be saved

## Chat with Chatbot / چیٹ بوٹ سے بات کریں

### مرحلہ 3: پیغام بھیجیں (Step 3: Send Message)

اب آپ اردو میں چیٹ بوٹ سے بات کر سکتے ہیں۔

Now you can chat with the chatbot in Urdu.

**مثال | Example Conversation**:

```
آپ: السلام علیکم! آپ کون ہو؟
You: السلام علیكم! آپ کون ہو؟
(Hello! Who are you?)

چیٹ بوٹ: علیکم السلام۔ میں ایک مدد کار بوٹ ہوں۔ میں آپ کی کیا مدد کر سکتا ہوں؟
Chatbot: السلام علیكم. I am a helpful bot. How can I help you?
(Hello. I am a helpful assistant bot. How can I help you?)
```

### آپ کیا پوچھ سکتے ہیں؟ | What can you ask?

✓ سوالات | Questions:
- "ROS 2 کیا ہے؟" (What is ROS 2?)
- "روبوٹ کس طرح کام کرتے ہیں؟" (How do robots work?)
- "نوڈ سے کیا مراد ہے؟" (What is a node?)

✓ مدد | Help:
- "مجھے اس لفظ کی تعریف بتائیں" (Define this term for me)
- "کیا آپ اردو میں جواب دے سکتے ہیں؟" (Can you answer in Urdu?)

✓ تکنیکی سوالات | Technical:
- "ROS سیٹ اپ کیسے کریں؟" (How to setup ROS?)
- "نوڈ کیسے بنائیں؟" (How to create a node?)

### پیغام بھیجنے کے اقدامات | Steps to send message:

1. **پیغام درج کریں | Type message**:
   - پیغام کے باکس میں اردو متن لکھیں
   - Type Urdu text in message box

2. **بھیجیں بٹن دبائیں | Click Send**:
   - "بھیجیں" یا "Send" بٹن پر کلک کریں
   - Click the "Send" or "بھیجیں" button

3. **جواب حاصل کریں | Get response**:
   - چیٹ بوٹ 3 سیکنڈ سے پہلے جواب دے گا
   - Chatbot will respond within 3 seconds
   - جواب اردو میں ہوگا (اگر دستیاب ہو)
   - Response will be in Urdu (if available)

## Using the Glossary / لغت استعمال کریں

### تکنیکی شرائط کی تشریح | Technical Terms Dictionary

چیٹ بوٹ میں ایک لغت ہے جہاں آپ تکنیکی اصطلاحات کے معنی اردو میں دیکھ سکتے ہیں۔

The chatbot has a glossary where you can see technical terms in Urdu.

### لغت کھولیں | Open Glossary

**مراحل | Steps**:

1. **لغت بٹن تلاش کریں | Find Glossary button**:
   - چیٹ بوٹ کے پاس "لغت" یا "Glossary" بٹن تلاش کریں
   - Look for "Glossary" or "لغت" button near chatbot

2. **بٹن پر کلک کریں | Click the button**:
   ```
   [بند کریں]  [لغت کھولیں]  [ترتیبات]
   [Close]  [Glossary]  [Settings]
   ```

3. **خول جائے گی | It will open**:
   - ایک نیا ونڈو یا ڈبہ کھل جائے گا
   - A window or modal will open

### اصطلاح تلاش کریں | Search for a term

**مثال | Example Search**:

```
تلاش کا ڈبہ: "ROS"
Search box: "ROS"

نتائج | Results:
┌─────────────────────────────┐
│ ROS 2                        │
│ اردو: ROS دوسرا ورژن      │
│ معنی: روبوٹ آپریٹنگ سسٹم  │
└─────────────────────────────┘
```

### دستیاب اصطلاحات | Available terms

لغت میں 150+ تکنیکی اصطلاحات اردو میں ہیں:
The glossary has 150+ technical terms in Urdu:

- **ROS**: روبوٹ آپریٹنگ سسٹم (Robot Operating System)
- **نوڈ**: الگ پروگرام (Node - separate program)
- **ٹاپک**: ڈیٹا بھیجنے کا راستہ (Topic - data path)
- **سروس**: درخواست اور جواب (Service - request/response)
- **کائنیمیٹکس**: حرکت کا مطالعہ (Kinematics - motion study)

## Save Your Preferences / اپنی ترجیحات محفوظ کریں

### آپ کی ترجیح محفوظ ہو جاتی ہے | Your preference is saved

جب آپ اردو منتخب کرتے ہیں، تو یہ محفوظ ہو جاتا ہے۔
When you select Urdu, it is automatically saved.

### دوبارہ لاگ ان کریں | Log in again

اگلی بار جب آپ لاگ ان کریں گے:
Next time you log in:

```
1. ویب سائٹ کھولیں | Open website
2. لاگ ان کریں | Log in
3. پہلے سے اردو منتخب ہوگا | Urdu will already be selected ✓
4. دوبارہ اردو منتخب کرنے کی ضرورت نہیں | No need to select again
```

### ترجیحات تبدیل کریں | Change preferences

اپنی ترجیحات تبدیل کرنے کے لیے:
To change your preferences:

1. **ترتیبات | Settings** بٹن تلاش کریں
2. **زبان | Language** بھاگ میں جائیں
3. اپنی پسند کی زبان منتخب کریں
4. "محفوظ کریں | Save" پر کلک کریں

## Troubleshooting / مسائل اور حل

### مسئلہ 1: اردو متن دکھائی نہیں دے رہا | Problem 1: Urdu text not showing

**علامات | Symptoms**:
- خانے (□) یا سوالیہ نشان (?) دکھائی دے رہے ہیں
- Boxes or question marks (?) appearing instead of text

**حل | Solution**:

```
ٹھیک کریں:
1. صفحہ دوبارہ لوڈ کریں | Refresh page (Ctrl+R)
2. کیش صاف کریں | Clear cache (Ctrl+Shift+Delete)
3. اپنا براؤزر اپڈیٹ کریں | Update your browser
4. ٹھنڈے براؤزر میں کھولیں | Try incognito window
```

### مسئلہ 2: زبان منتخب کرتے ہی ٹھیک ہوجاتا ہے | Problem 2: Language button disabled

**علامات | Symptoms**:
- اردو بٹن کلیک نہیں ہو رہا | Urdu button not clickable
- بٹن سرمئی ہے | Button is grayed out

**حل | Solution**:

```
آپ نے لاگ ان نہیں کیا:
1. لاگ ان کریں | Log in first
2. اپنا صارف نام درج کریں | Enter your username
3. اپنا پاس ورڈ درج کریں | Enter your password
4. اب اردو منتخب کر سکتے ہیں | Now you can select Urdu
```

### مسئلہ 3: جواب انگریزی میں آ رہا ہے | Problem 3: Response in English

**علامات | Symptoms**:
- اردو منتخب کیا لیکن جواب انگریزی ہے
- Selected Urdu but getting English response

**حل | Solution**:

```
ہو سکتا ہے اردو ترجمہ دستیاب نہیں ہو:
1. صفحہ دوبارہ لوڈ کریں | Refresh page
2. چیٹ بوٹ سے پوچھیں: "اردو میں جواب دیں"
3. مختلف سوال پوچھیں | Try different question
4. اگر مسئلہ برقرار ہے تو مدد طلب کریں
```

### مسئلہ 4: متن الٹی طرف جا رہا ہے | Problem 4: Text direction issues

**علامات | Symptoms**:
- متن بائیں سے شروع ہو رہا ہے
- Text starting from left instead of right

**حل | Solution**:

```
براؤزر کو دوبارہ شروع کریں:
1. براؤزر بند کریں | Close browser
2. دوبارہ کھولیں | Reopen
3. ترتیبات میں RTL دیکھیں | Check RTL in settings
```

### مسئلہ 5: عام مسائل | Problem 5: General issues

| مسئلہ | حل |
|------|-----|
| سست رفتار | انٹرنیٹ تیز کریں، صفحہ دوبارہ لوڈ کریں |
| کریش ہو رہا ہے | براؤزر اپڈیٹ کریں، کیش صاف کریں |
| لاگ ان نہیں ہو رہا | پاس ورڈ دوبارہ ٹائپ کریں |
| سوالات نہیں آ رہے | انٹرنیٹ کنیکشن چیک کریں |
