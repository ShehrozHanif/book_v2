## 🎯 User Features

### 1. Language Selection
- ✅ Authenticated users can select Urdu language from toggle button
- ✅ Guest users are prevented from accessing Urdu (401 Unauthorized)
- ✅ Language selection is persistent across sessions
- ✅ Language preference syncs across devices

**API**: `PUT /api/v1/users/me/language-preference`

### 2. Bilingual Chatbot Responses
- ✅ Real-time response translation to Urdu
- ✅ English content as fallback
- ✅ Response caching for performance (<3 seconds)
- ✅ Smart language switching without losing context

**API**: `GET /api/v1/chatbot/response/{template_key}?language=urdu`

### 3. RTL (Right-to-Left) Rendering
- ✅ Automatic RTL layout when Urdu selected
- ✅ Proper text alignment and spacing
- ✅ Code blocks remain LTR (left-to-right)
- ✅ Mobile and desktop support

### 4. Glossary with Urdu Translations
- ✅ 150+ technical terms with Urdu translations
- ✅ Pronunciation guides (transliterated)
- ✅ Example sentences in both languages
- ✅ Fast search (<500ms)

**API**: `GET /api/v1/glossary/search?q=ROS&language=urdu`

### 5. Preference Persistence
- ✅ localStorage for quick access
- ✅ Server-side database storage
- ✅ Cross-session synchronization
- ✅ Cross-device synchronization via API

## 📦 API Reference

### User Endpoints

#### Get Language Preference
```bash
GET /api/v1/users/me/language-preference
Authorization: Bearer {token}

Response: 200 OK
{
  "language": "urdu",
  "updated_at": "2026-02-10T12:00:00"
}
```

#### Set Language Preference
```bash
PUT /api/v1/users/me/language-preference
Authorization: Bearer {token}
Content-Type: application/json

Request:
{
  "language": "urdu"
}

Response: 200 OK
{
  "language": "urdu",
  "updated_at": "2026-02-10T12:00:01"
}
```

#### Get Chatbot Response
```bash
GET /api/v1/chatbot/response/{template_key}?language=urdu
```

## 🐛 Troubleshooting

### Issue: Urdu button disabled for authenticated users

**Solution**:
1. Verify user has valid JWT token
2. Check token includes `role` claim
3. Verify database user table has correct data
4. Check browser console for auth errors

### Issue: Urdu text not displaying correctly

**Solution**:
1. Verify font is loading from CDN
2. Clear browser cache (Ctrl+Shift+Delete)
3. Check RTL CSS is applied
4. Try incognito window
5. Verify browser supports Unicode/UTF-8

### Issue: Language preference not persisting

**Solution**:
1. Check localStorage is enabled
2. Verify API call succeeds (200 OK)
3. Check database has user_language_preference record
4. Clear browser data and retry
5. Check cross-domain cookie settings

### Issue: Performance degradation

**Solution**:
1. Check cache hit rate (target: >80%)
2. Verify database indexes exist
3. Monitor database connection pool
4. Check glossary size (should be <200MB)
5. Review rate limiting status
