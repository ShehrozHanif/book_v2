# Module 1: Foundations of Humanoid Robotics

This module introduces the fundamental concepts needed to understand humanoid robotics. You'll learn about the core principles, hardware components, and how robots perceive their environment.

## Chapters in This Module

1. **What is Humanoid Robotics?** - Understand the definition, history, and importance of humanoid robots
2. **Kinematics Basics** - Learn coordinate systems, forward kinematics, and inverse kinematics
3. **Dynamics & Motion** - Explore forces, motion equations, and dynamic modeling
4. **Sensors & Perception** - Understand how robots sense their environment
5. **Hardware Overview** - Get familiar with actuators, controllers, and power systems

## Learning Path

This module forms the foundation for all subsequent modules. Start with Chapter 1 and progress sequentially.

[Start Module 1 →](/book/docs/module-01/chapter-01)

## Prerequisites

- Basic understanding of physics (forces, motion)
- Familiarity with linear algebra is helpful
- Programming experience in Python recommended

## Outcomes

After completing this module, you will:
- Understand what humanoid robots are and why they matter
- Know the mathematics of robot kinematics
- Understand basic dynamics and motion
- Know how robots perceive their environment
- Be familiar with hardware components
