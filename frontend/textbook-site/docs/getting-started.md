# Getting Started Guide

Welcome! This guide will help you navigate the textbook effectively and get the most out of your learning experience.

## How to Use This Textbook

### 1. Choose Your Learning Style

This textbook is designed to accommodate different learning preferences:

#### Sequential Learner
**Best for**: Comprehensive understanding, building strong foundations

1. Start with [Module 1, Chapter 1](/book/docs/module-01/chapter-01)
2. Read each chapter in order
3. Complete exercises and code examples as you go
4. Use the "Next" button at the bottom of each page
5. Revisit previous chapters as needed

**Estimated Time**: 40-60 hours for complete course

#### Topic-Focused Learner
**Best for**: Specific skill development, experienced practitioners

1. Use the **Search Bar** to find topics of interest
2. Jump to relevant chapters using the **Sidebar**
3. Read related chapters for context
4. Reference the prerequisite sections at the start of each chapter

**Estimated Time**: 5-10 hours per module

#### Project-Based Learner
**Best for**: Hands-on learners, quick prototyping

1. Start with [Module 5, Chapter 22: Your First Project](/book/docs/module-05/chapter-22)
2. Reference earlier chapters as needed for specific concepts
3. Use the **Chatbot** to answer questions along the way
4. Build incrementally, testing as you go

**Estimated Time**: 15-25 hours to build first robot

### 2. Navigation Features

#### Sidebar Navigation
Located on the left side (desktop) or in the menu (mobile). The sidebar shows:
- All 5 modules
- All 22 chapters organized by module
- Current page highlighting
- Expandable/collapsible module categories

**Tip**: Click a module name to expand/collapse its chapters.

#### Search Functionality
Located in the top navigation bar. The search feature:
- Searches across all 22 chapters
- Returns results in under 500ms
- Highlights matches in context
- Shows chapter and module for each result

**Tip**: Use specific keywords like "inverse kinematics" or "ROS2 nodes" for best results.

#### Breadcrumb Trail
Located at the top of each page, shows your current location:
```
Docs > Module 1: Foundations > Chapter 01: What is Humanoid Robotics?
```

**Tip**: Click any breadcrumb to jump back to that level.

#### Table of Contents
Located on the right side (desktop), shows:
- All headings in the current chapter
- Current section highlighting (updates as you scroll)
- Click to jump to any section

**Tip**: Use this to quickly scan chapter structure before reading.

#### Previous/Next Buttons
Located at the bottom of each page:
- **Previous**: Go to the previous chapter
- **Next**: Go to the next chapter

**Tip**: Use keyboard shortcuts for faster navigation (see below).

### 3. Interactive Features

#### RAG Chatbot
The intelligent chatbot is powered by Retrieval-Augmented Generation (RAG) and can:
- Answer questions about textbook content
- Clarify complex concepts
- Provide additional examples
- Suggest related chapters
- Help debug code snippets

**How to Use**:
1. Click the chat widget in the bottom-right corner
2. Type your question (be specific for best results)
3. The chatbot will search the textbook and provide relevant answers
4. Ask follow-up questions for deeper understanding

**Example Questions**:
- "What is the difference between forward and inverse kinematics?"
- "How do I set up a ROS2 workspace?"
- "Explain the DH parameters in Chapter 2"
- "Show me an example of a URDF file"

**Tips**:
- Ask specific questions rather than general ones
- Reference chapter numbers if asking about specific content
- Request code examples when needed
- Use the chatbot to test your understanding

#### Code Examples
Every chapter includes syntax-highlighted code examples:
- **Python**: Primary language for examples
- **YAML**: Configuration files
- **XML**: URDF robot descriptions
- **Bash**: Terminal commands

**How to Use Code**:
1. Copy code using the copy button (top-right of code blocks)
2. Follow setup instructions in the chapter
3. Test code in your own environment
4. Modify and experiment with examples

**Best Practices**:
- Read the explanation before the code
- Understand the purpose of each code section
- Try modifying variables to see effects
- Use the chatbot if code doesn't work as expected

#### Diagrams and Visuals
Chapters include:
- System architecture diagrams
- Kinematic chain illustrations
- Control flow diagrams
- Mathematical visualizations

**Tips**:
- Zoom in on complex diagrams (click to enlarge)
- Reference diagrams while reading explanations
- Compare diagrams across chapters for connections

### 4. Keyboard Shortcuts

Speed up your navigation with keyboard shortcuts:

| Shortcut | Action |
|----------|--------|
| `/` | Focus search bar |
| `Esc` | Close search/modals |
| `←` or `n` | Previous chapter |
| `→` or `p` | Next chapter |
| `s` | Toggle sidebar (mobile) |
| `t` | Toggle table of contents |
| `Ctrl/Cmd + K` | Open command palette |

**Tip**: Use arrow keys for rapid chapter navigation during sequential reading.

### 5. Mobile Experience

The textbook is fully responsive and works seamlessly on mobile devices:

**Mobile Features**:
- Tap the menu icon (☰) to access the sidebar
- Swipe left/right to navigate between chapters
- Table of contents appears at the top of each chapter
- All code examples are horizontally scrollable
- Chatbot optimized for mobile screens

**Best Practices**:
- Use portrait mode for reading text
- Switch to landscape for code examples and diagrams
- Bookmark frequently accessed chapters
- Use the search feature to find content quickly

### 6. Learning Tips

#### For Maximum Retention
1. **Take Notes**: Summarize key concepts in your own words
2. **Practice Actively**: Run and modify all code examples
3. **Test Yourself**: Use the chatbot to quiz your understanding
4. **Space Learning**: Take breaks between modules
5. **Teach Others**: Explain concepts to solidify understanding

#### For Concept Mastery
1. **Read Prerequisites**: Check the "Prerequisites" section of each chapter
2. **Review Math**: Don't skip mathematical derivations
3. **Connect Concepts**: Use breadcrumbs to see how topics relate
4. **Ask Questions**: Use the chatbot liberally - there are no dumb questions
5. **Build Projects**: Apply concepts in hands-on projects

#### For Efficient Learning
1. **Skim First**: Read headings and summaries before diving deep
2. **Use Search**: Find exactly what you need without browsing
3. **Bookmark**: Save important pages for quick reference
4. **Follow Links**: Click on cross-references to related topics
5. **Set Goals**: Aim to complete one chapter per session

### 8. Module Overview

Here's what to expect from each module:

#### Module 1: Foundations (5 Chapters)
**Purpose**: Build fundamental understanding
**Key Topics**: Kinematics, dynamics, sensors, hardware
**Prerequisites**: Basic math and physics
**Time**: 8-12 hours

#### Module 2: ROS2 & Development (5 Chapters)
**Purpose**: Learn software development for robots
**Key Topics**: ROS2, URDF, simulation, motion planning, control
**Prerequisites**: Module 1, Python programming
**Time**: 10-15 hours

#### Module 3: Advanced Kinematics & Motion (5 Chapters)
**Purpose**: Master complex motion patterns
**Key Topics**: Real-time control, walking, manipulation, whole-body control
**Prerequisites**: Modules 1-2, advanced math
**Time**: 12-18 hours

#### Module 4: Learning & Control (1 Chapter)
**Purpose**: Explore AI-based control methods
**Key Topics**: Reinforcement learning, imitation learning, neural networks
**Prerequisites**: Modules 1-3, machine learning basics
**Time**: 3-5 hours

#### Module 5: Applications & Future (6 Chapters)
**Purpose**: Apply knowledge and explore frontiers
**Key Topics**: Debugging, applications, ethics, emerging tech, projects
**Prerequisites**: All previous modules
**Time**: 8-12 hours

### 9. Troubleshooting

#### Page Not Loading
1. Check your internet connection
2. Refresh the page (F5 or Ctrl+R)
3. Clear browser cache
4. Try a different browser

#### Code Examples Not Working
1. Verify you've completed the setup steps
2. Check for typos when copying code
3. Ensure correct Python/ROS2 version
4. Ask the chatbot for help
5. Check system compatibility

#### Chatbot Not Responding
1. Refresh the page
2. Try rephrasing your question
3. Check internet connection
4. Clear browser cookies

#### Search Not Finding Results
1. Try different keywords
2. Use more specific terms
3. Check spelling
4. Browse the sidebar manually

### 10. Best Practices

#### Do's

- Complete hands-on exercises
