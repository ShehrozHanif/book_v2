ENDPOINT SPECIFICATION
================================================================================

REQUEST:
  POST /api/v1/chat/embed
  {
    "chunks": [
      {
        "content": "string (10-5000 chars)",
        "module": "string (1-100 chars)",
        "chapter": "string (1-200 chars)",
        "section": "string (1-200 chars)"
      }
    ],
    "collection_name": "string (optional, default: textbook_chunks)"
  }

RESPONSE:
  HTTP 200 OK
  {
    "success": true,
    "chunks_embedded": 2,
    "collection": "textbook_chunks",
    "message": "Successfully embedded 2 passages into 'textbook_chunks' in 0.45s"
  }

ERROR RESPONSES:
  400: Empty chunks list
  422: Invalid chunk format
  500: Embedding or Qdrant failure
